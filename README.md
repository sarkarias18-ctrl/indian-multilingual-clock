# indian-multilingual-clock
 A dementia/Alzheimer-friendly digital clock for Indian elders 🧓🏽👵🏽
Supports **23 Indian languages** with clear time, date, and time-of-day visuals. 

## 👁️ Purpose  
This app helps elderly individuals — especially those with **dementia, Alzheimer’s, low vision, or memory challenges** — understand:

- Current Time (large display)
- Day of the Week
- Full Date
- Time of Day (Morning / Afternoon / Evening / Night)
- Visual cues: sky gradient, icons, and animated sun/moon

---

## 🌍 Supported Indian Languages (23)
Assamese, Bengali, Bodo, Dogri, Gujarati, Hindi, Kannada, Kashmiri, Konkani,  
Maithili, Malayalam, Manipuri, Marathi, Nepali, Odia, Punjabi, Sanskrit,  
Santali, Sindhi, Tamil, Telugu, Urdu.

---

## 🎨 Features
- Large, dementia-friendly high-contrast text  
- Animated sunrise → day → sunset → night background  
- Curved sun/moon movement across the screen  
- Automatic brightness dimmer  
- Super-soft night mode for bedrooms  
- Clean, simple, soothing interface  
- Manual language selector  
- No clutter or distractions
